# 🚀 Navoa Virtual Machine & REPL

O Navoa é uma máquina virtual e ambiente REPL multilingue leve, concebido para executar scripts personalizados com suporte nativo para 6 idiomas.

---

## 🌍 Idiomas Suportados
No arranque, podes escolher o teu idioma de preferência:
1. **Português (PT)**
2. **English (EN)**
3. **Español (ES)**
4. **Français (FR)**
5. **Italiano (IT)**
6. **Deutsch (DE)**

---

## 💡 Guia Rápido de Palavras-Chave

| Ação | PT | EN | ES | FR | IT | DE |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Declaração de Variável** | `seja` | `let` | `var` | `soit` | `sia` | `sei` |
| **Imprimir / Mostrar** | `escreve` | `print` | `escribe` | `affiche` | `stampa` | `drucke` |
| **Condicional (Se)** | `se` | `if` | `si` | `si` | `se` | `wenn` |
| **Senão** | `senao` | `else` | `sino` | `sinon` | `altrimenti` | `sonst` |

---

## 🛠️ Comandos Nativos do REPL
Dentro da consola interativa, podes usar comandos de gestão independentemente da língua do código:
* **`abrir "ficheiro.nav"`** -> Carrega e executa um script.
* **`gravar "ficheiro.nav"`** -> Guarda o histórico da sessão num ficheiro.
* **`ver`** -> Mostra o código da sessão atual adaptado ao idioma do teu perfil.
* **`limpar`** -> Limpa o histórico atual.
* **`sair`** -> Fecha o Navoa.
